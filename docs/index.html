Truss normalisation

A Lean 4 formalisation of the normalisation of labelled open truss bundles: Chapter 2 of Yuhang Wei's transfer report.

Build

With elan installed:

git clone https://github.com/EricWay1024/truss-normalisation
cd truss-normalisation
lake exe cache get
lake build
lake env lean CheckAxioms.lean

Lean and Mathlib are pinned to v4.28.0. The last command fails if any theorem or definition in Truss.Transfer depends on an axiom other than propext, Classical.choice and Quot.sound.

Scope

Trusses are coordinate models. A comparison with the abstract definitions of the FCT book is not part of this package, and neither is the C++ truss library. The constructions are noncomputable: they are proved correct, not run.
