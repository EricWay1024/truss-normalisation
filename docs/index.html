Reproduce the check

With elan installed:

git clone https://github.com/EricWay1024/truss-normalisation
cd truss-normalisation
lake exe cache get
lake build
lake env lean CheckAxioms.lean

Lean and Mathlib are pinned to v4.28.0. The axiom check rejects dependencies outside propext, Classical.choice and Quot.sound for all theorems in Truss.Transfer.

What this checks

The formal statements in the linked files, with their stated hypotheses. This is not a verification of the C++ implementation or every sentence of the current manuscript, and its noncomputable constructions are not an executable normaliser. Historical audit labels refer to an earlier draft; a fresh manuscript-correspondence review is separate work.
